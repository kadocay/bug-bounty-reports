## #1 recommended first pick

**RedStone Smart Contracts (HackenProof)** — https://hackenproof.com/programs/redstone-smart-contracts

Why: the only top-tier program this run whose **entire scope is public GitHub repos** (redstone-oracles-monorepo) — you can read and review every target with no login, no KYC gate, no access request. Critical pays $50k–$250k with a high floor, the program is only 3 weeks old (216 submissions but **$0 paid out** — still wide open), and its sibling RedStone Web program publishes a **3-business-day first-response SLA**, so triage is fast. Costs are trivial ($10 submission fee, 150 HackenProof reputation). Runner-up if you prefer a bigger single ceiling: Paxos Labs ($500k max, $10k critical floor, 15 well-defined assets on Ethereum).
